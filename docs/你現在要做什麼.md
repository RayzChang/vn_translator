# 你現在要做什麼

## 不想登入、不同步
- 執行 `npm run dev`，開 http://localhost:5173，設定裡填 API 金鑰就好。金鑰只存這台電腦。

## 要登入、要多裝置同步
1. GitHub 開倉庫，把專案 push 上去。
2. Vercel 開專案，Import 那個倉庫，Deploy。
3. Vercel 專案裡：Storage 建 Postgres（或用 Neon 拿連線字串）→ Settings → Environment Variables 加 `DATABASE_URL`、`ENCRYPTION_KEY`、`JWT_SECRET`（後兩項自己設兩串密碼）→ Redeploy。
4. 用給的網址註冊、登入，設定裡存一次金鑰，之後換裝置登入即可。

細節可看 `P2-後端部署與環境變數.md`，有問題再查。
